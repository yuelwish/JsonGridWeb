# 人工清单：编辑器搜索的匹配落点与揭示滚动

`src/search-scroll.ts` 只改滚动位置，源码层回归（`npm run verify`）能守住接管形态与公式，
但「看起来对不对」必须在浏览器里确认。本文是唯一的浏览器验收口径，改该模块后逐条走。

前置：`npm run build`，用 `dist/index.html`（或 `npm run dev`）打开页面，点「加载示例数据」，
把左侧编辑器的滚动条拉回顶部，然后点工具栏搜索按钮（或 Cmd/Ctrl+F）。

## 1. 首个匹配落在视口中间

1. 搜索框输入 `true`，按 Enter。
2. 期望：匹配（第 54 行 `"email": true`）**完整可见且位于视口垂直中部**，不被上边缘裁切，
   也不被搜索面板遮住。落点比值 = 匹配顶边相对滚动容器顶边的偏移 / 容器高度。

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 视口 472px（dist 实测） | `-19px`（-0.024，被上边缘裁切且藏在搜索面板后） | `236px`（**0.500**，居中） |

3. 期望：这一步**没有动画**——首个匹配是直接出现在中间，不是从边缘滑过来。

## 2. 后续匹配从最下方`上来一点点`

1. 接着点「下一个」（或 Enter）。
2. 期望：视口先跳到匹配大致所在的位置，匹配**此刻贴着视口底缘（完整可见）**，
   然后在约 150-300ms 内**上升一小段（视口高的 8% 左右，实测 37px）**停在底缘偏上。
3. 期望能看出「从下方冒出来」的方向感；不应出现「匹配从顶部滑下来」。

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 视口 472px，第 2 个匹配 | `-19px`（单帧跳变，落在顶部之外） | 起点 `459px`（0.972 贴底缘）→ 终点 `426px`（**0.903**），11 帧递增 |
| 视口 472px，第 4 个匹配 | 单帧跳变 | 起点 `2724` → 终点 `2762`（**0.900**），10 帧递增 |

4. 若下一个匹配**本来就在视口内**，期望完全不动（示例数据里第 3 个匹配紧邻第 2 个，属于这种情况）：
   只换高亮，不滚动。

## 3. 向上查找镜像到底缘对侧

1. 在靠后的匹配处点「上一个」。
2. 期望：匹配贴着**视口顶缘**出现，再向下移入一小段（落点比值 0.05~0.15）。

| 场景 | 修复后实测 |
|---|---|
| 视口 445px（隔离探针） | 起点 `5px`（0.011 贴顶）→ 终点 `42px`（**0.094**），9 帧递增 |

## 4. 打断与降级

- 揭示过程中滚一下鼠标滚轮：动画**立即停住**，视口不再自行移动。
- 系统开启「减少动态效果」（macOS 辅助功能 / Windows 动画效果关闭）后重做第 2 条：
  匹配直接落位，没有渐次移动。
- 在大文件（例如 `?json=` 载入上万个键）里连续按「下一个」：内容区域可能瞬移，
  但匹配本身仍从边缘移入，且动画不打嗝、不掉帧到单帧跳变。

## 5. 计数器「N of M」

1. 打开面板：`0 of 0`。
2. 只输入 `true`、不按 Enter：`0 of 10`（查询已知、还没有当前匹配）。
3. 按 Enter：`1 of 10`；每按一次「下一个」序号 +1（`2 of 10`、`3 of 10`…），「上一个」回退。
4. 输入不存在的词：`0 of 0` 且搜索框红框；清空查询：`0 of 0` 且不红。

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 输入 `true` 后按 Enter | `1 of 1` | **`1 of 10`** |
| 再按「下一个」 | `1 of 9`（总量与序号都随视口漂移） | **`2 of 10`** |

总量必须与视口无关：滚动、「下一个」、切换视图后再看，分母都不变。分母是整篇文档的匹配数，
不是屏幕上渲染出来的高亮个数。

## 6. 回归面

- GRID 视图的搜索面板与「跳到编辑器」行为不受影响（本次只改编辑器搜索面板）。
- 错误高亮（JSON 语法错误）的定位行为不变。
- 左侧自绘滚动条的滑块位置跟随动画，松手后不与内容脱节（见 `verify-scrollbar`）。

## 量化判定

| 指标 | 阈值 |
|---|---|
| 首个匹配落点比值 | 0.40 ~ 0.60 |
| 后续匹配落点比值 | 0.85 ~ 0.95 |
| 向上查找落点比值 | 0.05 ~ 0.15 |
| 匹配是否完整可见 | 顶边 >= 容器顶边，底边 <= 容器底边 |
| 揭示帧数 | 距离超过一行时 > 3 帧（不是单帧跳变） |
