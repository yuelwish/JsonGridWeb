# GRID 长值不裁剪 — 浏览器实测清单

> 本清单验证 GRID 视图长值单元格不再被裁剪为省略号。
> 每次修改 grid.ts 或 style.css 后应重跑。

## 环境

- 构建产物：`dist/index.html`（`npm run build`）
- 本地服务：`python3 -m http.server 7766 --directory dist`
- 浏览器：Chrome / Firefox / Safari 任一

## 用例 1：长字符串值完整可读

1. 访问 `http://127.0.0.1:7766/?url=/__a.json`（或手动粘贴 `/dev/shm/a.json` 内容）
2. 点「▶」渲染 GRID
3. 点「展开全部」
4. 找到 `tree` 单元格（含 `263608457272233984`）
5. 验证：
   - 单元格文本长度 = 8548（原值长度）
   - 页面 DOM 内 U+2026（省略号）出现次数 = 0
   - 单元格可横向滚动（scrollWidth > clientWidth）
   - 悬停提示携带完整值（title 属性长度 = 8548）

## 用例 2：表宽有上限

1. 同上进入 GRID 视图
2. 验证：
   - `.virtual-grid-body` 的 scrollWidth ≤ 列宽总和（约 1200-3000px）
   - 不会因长值膨胀到 63000px+

## 用例 3：行高不因长值异常变化

1. 同上进入 GRID 视图
2. 验证：
   - 各行 offsetHeight 在 38-130px 范围内（嵌套表格会增高，但不会到 500px+）
   - 虚拟滚动正常（可上下滚动，行号连续）

## 用例 4：内置样例无多余滚动条

1. 点「加载示例数据」
2. 点「▶」渲染 GRID
3. 点「展开全部」
4. 验证：
   - 所有单元格 scrollWidth ≤ clientWidth（无横向滚动条）
   - 宽嵌套表格保持原有 table-in-cell 观感

## 用例 5：搜索高亮状态下长值不裁剪

1. 同用例 1 进入 GRID 视图并展开全部
2. 点 GRID 工具栏「搜索」按钮
3. 输入 `263608457272233984`
4. 验证：
   - `tree` 单元格文本长度仍 = 8548
   - 页面 DOM 内 U+2026 出现次数 = 0
   - 搜索高亮正常（匹配文本有背景色）

## 用例 6：排序状态下长值不裁剪

1. 同用例 1 进入 GRID 视图并展开全部
2. 点列头排序图标（如有）
3. 验证：
   - `tree` 单元格文本长度仍 = 8548（或滚出视口但代码层面保证不裁剪）
   - 页面 DOM 内 U+2026 出现次数 = 0
