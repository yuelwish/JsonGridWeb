# 编辑器搜索面板锚定内容区右缘而非编辑器外缘

编辑器搜索面板（复刻原站 Ace searchbox 的悬浮框）定位时锚定 JSON 编辑器的**内容区**右缘（`.cm-scroller` 的可见内容右缘，即排除垂直滚动条），并以内容区宽度为 `max-width` 上限、输入框可弹性收缩；而不是像原站 Ace 的 `right: 0` 那样贴编辑器外缘。

原因：垂直滚动条住在编辑器外缘，面板右缘若与外缘齐平会盖住滚动条；窗口窄于面板自然宽（约 371px）时，固定宽度的面板会溢出到分隔条与 GRID 面板。锚定内容区 + `max-width` 上限 + 输入框收缩，三个约束一起保证滚动条始终可见、面板永不溢出 JSON 面板。这是对「复刻 Ace searchbox」目标的修正：复刻的是外观与功能，不是遮挡滚动条的副作用。

已否决的替代方案：CodeMirror 原生顶栏面板（非悬浮）能天然避让，但失去 Ace searchbox 外观；最小修补只钳制 `left` 能止住溢出，但宽窗口下仍会盖滚动条。
